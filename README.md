#### [🎮 Copa FEDEPE de Egames](https://github.com/gustavo123c/Fedepe-site)

Plataforma de campeonatos escolares de eSports da **Federação do Desporto Escolar de Pernambuco**.
Feita com **HTML, CSS e JavaScript puros**, sem etapa de build:

- Inscrição com regras de negócio encadeadas (equipe, prazo, vagas)
- Autorização dos pais e da escola com **assinatura digital em canvas**
- Chaveamento, calendário, ranking e transmissões (YouTube/Twitch)
- Painel ADM para validar cadastros e gerenciar as lives
